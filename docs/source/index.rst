OCP-Tool Documentation
======================

OpenIFS Coupling Preparation Tool for climate model coupling.

OCP-Tool generates OASIS3-MCT input files, modifies the OpenIFS land-sea mask,
and adjusts runoff maps to fit a given FESOM2 mesh or NEMO grid.
